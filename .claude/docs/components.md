## DatabaseAdapter + web-adapter (AR-2 · 2026-07-27 · commit e55010f)
Platform-agnostic SQLite seam (`packages/core/src/db/adapter.ts`) + its browser impl (`apps/web/src/db/`).
- **`DatabaseAdapter`** interface: `open` / `migrate` / `createDrizzle` / `exists` / `destroy`. `SqliteDriver` is the
  per-platform raw-SQL surface (async: `exec`/`run`/`query`/`values`/`batch`/`close`).
- **Async** — wa-sqlite's Factory API is async-only, so `DrizzleDb = SqliteRemoteDatabase<schema>` ('async') built via
  `createDrizzleProxy` (drizzle-orm/sqlite-proxy). Encryption OFF in M1.0 (optional `sqlCipher` seam → M3).
- **Web** (`apps/web/src/db/`): `web-driver.ts` (async driver on wa-sqlite `statements()`), `worker.ts` (Web Worker
  host + in-worker proof), `web-adapter.ts` (`AccessHandlePoolVFS`/OPFS). Runs in a Worker (sync OPFS handles are worker-only).
  The main↔worker RPC (`client.ts`) proxies `open/query/run/values/close`; **`values` (the Drizzle-proxy read path) landed
  with MOD-notes ② · B1** — the first main-thread Drizzle consumer (`exec`/`batch` stay deferred, unused by `createDrizzleProxy`).
- Tests: `web-adapter.test.ts` (Node contract over better-sqlite3, 6/6). Browser open/persist proof → LIF-103.
- **TagPicker** (`apps/web/src/app/notes/tag-picker.tsx`, MOD-notes ② B6) — controlled multi-select tag picker: search live tags (pure `filterTags`/`hasExactTag`) + create-on-miss (mirrors B3's `[[` picker). Composes UI-1 Popover/Input/Button; **`inline` prop** renders the body without a portal (REQUIRED inside a modal Dialog — a Popover dismisses it). Used by the create-with-tags Dialog (inline) + the note-detail rail (Popover). Shared `TagPickerBody`.
- **Notes filter bar** (in `notes-collection.tsx`, MOD-notes ② B6) — 3 explicit "show only" controls (Favorites/Archived toggle Buttons with `aria-pressed`, tag via UI-1 Menu over `useTags()`) → the ephemeral `notes-view-store` filter → `useNotesList(filter)` → ① `listPages`. Default `{}` (no default-hide).
