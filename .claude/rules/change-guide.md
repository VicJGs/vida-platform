# Change guide: vida-platform

The stages every change here goes through, in order.

## 1. Read what the issue names

Fetch the units the Linear issue links (MOD, FLOW, ARCH, ADR, REF) with `get_context`, by ID or the issue text, plus the CLAUDE.md of every layer you touch. Until a subject has a unit, read only the paths the issue names; ask before opening anything else.

## 2. Trace the flow

Follow the UI read/write through the service, repository and encrypt seam; cross-module reads go through the shared foundation/views ViewProviderRegistry. Fetch the ARCH unit for the flow by ID; until it has one, open only the architecture path the issue names.

## 3. Observe real state

`pnpm dev:app` for the local-first app (no server in M1). Live-store tests run over better-sqlite3; browser persistence uses the Playwright harness in apps/web/e2e (window.__vidaDb backdoor). Date code gets TZ-forced tests.

## 4. Where problems are written up

The Linear issue (team LIF); a decision that outlives the issue becomes an ADR in docs/core/decisions/; recurring failures in docs/core/known-failures.md, each entry linking the test or check that now prevents it. Never write plan, spec, status, session or log files; history is git.

## 5. Plan

The Linear issue is the plan: scope, acceptance and status live there. Never write plan files. Register a service in apps/web/src/db/composition-root.ts only in the entity's closing slice; `pnpm check:entity-live` then fails until it has a route, a hook and an e2e spec.

## 6. Landmines

App-wide write lock (BR-RT-LOCK): no nested db.transaction. React Query errored queries need retryOnMount:false on state-swapped surfaces. Editing @vida/types needs a dist rebuild before @vida/core typecheck. better-sqlite3 ABI vs Node. On macOS 12, run e2e locally with PW_EXECUTABLE_PATH set to Brave (see apps/web/e2e/CLAUDE.md).

## 7. Validate

`pnpm check` (format:check + lint + typecheck + test + e2e); packages/core has no lint script, so run eslint from the repo root. Each acceptance bullet has a user-flow e2e in apps/web/e2e that clicks it through in the real app.
