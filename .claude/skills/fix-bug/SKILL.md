# Fix a reported defect with a regression test.

## Rules for this operation

## Steps

1. Read the error fully; classify it isolated or structural (structural → plan first and ask).
2. Check docs/core/known-failures.md for the pattern.
3. Reproduce with a failing test at the lowest layer that shows it (TZ-forced for date code; Playwright for OPFS/worker behaviour).
4. State the root cause, apply the minimal fix, and grep for sibling call sites with the same defect.
5. Record a new recurring pattern in docs/core/known-failures.md; run `pnpm check`.
