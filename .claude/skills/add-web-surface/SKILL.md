# Add a screen or surface to apps/web on @vida/ui.

## Inputs

- the frontend spec / specimen for the surface
- the service reads and writes it uses
- the governing state-conventions

If an input is missing, ask; never guess.

## Rules for this operation

- apps/web never registers a `beforeunload` listener (cancelable → a live page with a dead worker); teardown is pagehide/pageshow in db/boot.ts.
- packages/ui/src/themes/{tokens,themes,fonts,motion,shadow}.ts are generated by build-tokens.mjs: change the source and rebuild, never hand-edit.

## Steps

1. Read docs/specs/foundation/frontend-source-of-truth.md, docs/core/architecture/state-conventions.md and the CLAUDE.md of the apps/web/src area you touch.
2. Build from @vida/ui primitives and tokens; add a primitive to packages/ui only when no existing one fits.
3. Read through React Query over getServices() with honest loading/empty/error states (explicit Retry; retryOnMount:false where the surface swaps state).
4. Register any new service in apps/web/src/db/composition-root.ts only in the entity's closing slice.
5. Add the Vitest + Testing Library tests and a Playwright spec using apps/web/e2e/fixtures.ts.
6. Run the Visual Gate in a real browser (light + dark, 375/768/desktop), then `pnpm check`.
