## 4. Key decisions & lessons locked

- **Encryption/auth/sync are OFF in M1.0** (ADR-017): the repository is an encrypt/decrypt **seam** (pass-through,
  empty `[E]` set, lazy vault key); sync accrues to a queue but never flushes (`SyncNotActivated`). Activation →
  M3 (encryption) / M4 (sync). Every crypto/auth touchpoint is a documented deferred seam, not a stub-to-fill.
- **Hand-written SQL migrations** (ADR-016), not drizzle-kit; forward-only at boot.
- **Design models vs rendered components** (UX-3/4/5/6): the UX-* deliverables are typed declarative models +
  architecture docs, rendered later by UI-4 — no premature Visual Gate. Reuse a canon by **type**, not by runtime.
- **Frontend documentation convention** (ADR-018 §3.6 + `frontend-source-of-truth.md §F`): visual-gated components
  (UI-1/2) and apps/web design models (UX-1..6) are documented by **layer-`CLAUDE.md` + architecture-doc + specs**,
  *not* `current-*` — so their absence from the `current-*` set is intentional, not a §XXIX gap.
- **Delivery routing** (this repo): the `#` global build order in `reconstructed-structure.md` is authoritative;
  `tracker_sync --next` is advisory (dependent-count tie-break); the sub-wave gate (`-a∥-b → -c → -d`) overrides a
  raw `#` walk.
