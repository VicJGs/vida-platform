So the headline isn't a prettier grid, it's the Agenda range: the same dated data read as an actionable, daypart-grouped schedule (your P3 "① Schedule · must/can" capture). A single range switcher swaps all five; Month stays the refined grid from mockup 1. Editorial preset only here — once the shape is right, I render the full preset × mode × density matrix.

The model (one renderer, five ranges)

  • Agenda is the answer to "see what I need to do": timed items show a time, dayparted items group under Morning / Afternoon / Evening, each carries a Must / Can weight + done checkbox. The crush is gone — nothing hides behind "+2 more".
  • Week / Day = a time-column for precise scheduling; all-day / dayparted items sit in a strip on top. (Day = Week zoomed to one column — not mocked separately.)
  • Month = the refined grid (mockup 1). Year = a zoom-out overview; density dots show busy days, click a month to drill in.
  • Still a read-only lens (ADR-007): checking a box / moving an event is a write = the owning module's capability, composed in — the renderer only displays.
  • One range switcher (toolbar, `aria-pressed`) swaps ranges; the switcher reflows to a dropdown under 768 (the Collection precedent).
