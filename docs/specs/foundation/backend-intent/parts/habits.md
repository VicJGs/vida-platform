# Backend Intent — Part A: habits

> Module: habits (standard module · Wave 1 — independent domain, no upstream owner). It **feeds** three cross-module edges: contributes to Purpose metrics (`contributions`), feeds the economy (`grant_currency(XP)`), and is tagged (`entity_tags`). It is **consumed by** Journal `/summary`, Purpose, Projects (`project_habits`), and Gamification. Sources read: `docs/features/habits/{identity,structure-data,business-rules,contract,conventions}.md` (S1) · `docs/intake/habits.md` (S2) · `docs/roadmap/m1.1-delivery-plan.md` §9 (S3 — **no MOD-habits bucket exists**; §9 covers only the M1.1 wave; habits is an M1.2 module per delivery-table:153) · `docs/specs/foundation/realignment-master-plan/part-1.2-reruns/habits.md` (S4 — ✅ IMPLEMENTED 2026-07-24) · `packages/core/src/services/habits/CLAUDE.md` (S7 — directory-home stub only, no logic).
>
> Boundary note (ADR-020): items with both a derivation/logic face and a state/render face are SPLIT into a service row + a UI row (P6). Habits is a genuine service-heavy module (CRUD + streak/analytics derivation-from-ledger + effect production + today-list computation). The **4 view surfaces** (Dashboard · today-list Calendar/List/Checkbox · per-habit standalone · All-Habits Overview) and optimistic completion UI are UI (P6). The `@vida/core` habit services do **NOT** exist yet (contract.md:6, service CLAUDE.md:14-16) — every service row below is DESIGNED interface, authored at the habits build phase (ADR-016/017).
>
> Cross-cutting: every effect-producing item rides the ADR-004 S4 catalogue / R1/R2 rails (Sessions-owned), the ADR-012 economy feeder `grant_currency`/`consequence_ledger` (Gamification-owned), the ADR-011 `contributions` ladder + `streak(habit)` M5 read seam (Purpose/measurement-owned), the ADR-006 `entity_tags` primitive (Spaces-owned), the Notes `pages` polymorphic seam (Notes-owned). Habits names the contracts it rides; it does not author them. The As-is FACT floor = 2 live tables (`habits` `schema.ts:253`, `habit_completions` `:278`) + inline `habits.tags` + the denormalized streak cache; the retired forward tokens (`purpose_habits:413`, `page_tags:121`, `xp_history:1213`) are live FACTs recorded then retired in `[INTENT]` (R6 two-tier).
