# Backend Intent — Part A: finance

> Module: finance (standard module · Wave 1 — independent domain, no upstream owner). It **owns** the money `store` economy substrate (E6) and executes the `move_money` Additive effect (E4); it **feeds** Journal `/summary` (today's transactions + net-worth snapshot), Purpose financial targets (net-worth/savings), and Gamification (transaction-create / milestone achievement events). It is a **consumer** of `entity_tags` (Spaces-owned, SP1), the Notes `pages` polymorphic seam (Notes-owned), Preferences (base currency / recurring-mode / persisted-aggregates opt-in / import personalization), and the ADR-014 ingestion rails (X1/X5/X8). Sources read: `docs/features/finance/{identity,structure-data,business-rules,contract,conventions}.md` (S1) · `docs/features/finance/fiscal-legal/{identity,structure-data,business-rules,contract,conventions}.md` (S1 sub-context) · `docs/intake/finance.md` (S2) · `docs/roadmap/m1.1-delivery-plan.md` §9 (S3 — **NO MOD-finance bucket exists**; §9 covers only the M1.1 wave; finance is an M1.2 module per delivery-table:153) · `docs/specs/foundation/realignment-master-plan/part-1.2-reruns/finance.md` (S4 — ✅ IMPLEMENTED 2026-07-24, LITE gate passed) · `packages/core/src/services/finance/CLAUDE.md` (S7 — directory-home stub only, no logic).
>
> Boundary note (ADR-020): items with both a derivation/logic face and a state/render face are SPLIT into a service row + a UI row (P6). Finance is the platform's heaviest derivation-and-economy module: derived-balance ledger (FN-3), net-worth over the `store` tree (FN-7/FN-15), investment value/gain-loss + monthly totals (FN-6), recurring forecast/materialize (FN-5), CSV/OFX import-reconcile (FN-9/X8), multi-currency FX conversion (FN-8), the `move_money` effect handler (FN-16), and the derived Commitments layer (FN-14). The **9 view surfaces** (switchable dashboard, account standalone, all-transactions + timeframe, all-assets/investments/liabilities, liability-payment view, import wizard, budgeting) and optimistic form/import-review UI are UI (P6). The `@vida/core` `models/finance.ts` + `services/finance-service.ts` are **empty placeholders (0 lines)** (contract.md:6-8, service CLAUDE.md:14-16) — every service row below is DESIGNED interface, authored at the finance build phase (ADR-016/017).
>
> Cross-cutting: `store` IS Finance-owned (name it fully); every other substrate is cite-not-re-spec — `entity_tags` (Spaces/SP1), `currencies`/`consequence_ledger`/`grant_currency`/`lock_currency` + the rule→consequence coordinator (Gamification-owned; Finance names only its `move_money`/`store`/`is_locked` members), the ADR-010 grant envelope `external_in_ok`/`external_out_ok` (Auth/Spaces-owned), the ADR-014 ingestion rails, ADR-015 AI layer (fiscal-legal only), the Notes `pages` seam, the sync/encryption foundation substrates.
