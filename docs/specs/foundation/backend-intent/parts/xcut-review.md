# Backend Intent — Part A: xcut-review

> **Context:** cross-cutting review engine (ADR-005 study-method service framework; SM-2 as one preset).
> **Substrate status:** `packages/core/src/foundation/review/` is a **0-LOC stub** — directory home only
> (ADR-018). Per its `CLAUDE.md`, engine logic + tables are authored **PER-FEATURE at build phase**
> (ADR-016 §3.5 / ADR-017), i.e. by **MOD-knowledge at M1.2** (delivery-plan §7). No engine code or DDL
> lives in the substrate today. `[FACT: packages/core/src/foundation/review/CLAUDE.md:14-15]`
> **Ownership split (the core rule):** the **generic review engine is Knowledge-owned** (scheduling, curves,
> `method_bindings`, `review_events` log, mastery derivation, the `dueIn` provider). A **study method** is a
> pluggable capability (`kind=study_method`, ADR-008) that owns only its content unit + interaction; it
> **emits** signals and **never** computes scheduling or mastery. `[FACT: ADR-005 §3.1/§3.2; knowledge/business-rules.md KN-8/KN-9]`
> **Provisional homes** below name **review-engine (Knowledge-owned)** for the shared engine surfaces and
> **study-method (per-service)** for the plugin surfaces; final homing is P3.
