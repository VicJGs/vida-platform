# Backend Intent — Part A: notes-and-pages

> Context: notes-and-pages is the platform's **unifying integration hub** (in-degree 14, out-degree 0,
> Wave-0 foundation) — a polymorphic `pages` table + `page_links`/`note_attachments` satellites, consuming
> the AR-6 Spaces substrate (`entity_tags`/`entity_links`/`tags`) and the AR-8 `BacklinkResolver`. The
> `@vida/core` Notes & Pages **service** was BUILT in MOD-notes ① (2026-08-21, LIF-131) then removed on this
> rebuild branch; `current-spec.md` + `current-business-rules.md` record the shipped surface, cited to file.
> Boundary drawn per ADR-020; a row with both a derivation and a state face is SPLIT into a service + UI row.
> Two hard delegation boundaries: entity-link/tag **WRITES** → AR-6 `SpacesService`; entity-link **READS** →
> AR-8 `BacklinkResolver` (ADR-018 §3.3) — Notes composes, never re-implements. The `/summary` aggregation
> ENGINE is NOT here — it is MOD-journals; Notes owns only `summary_config` storage + the block interface.
