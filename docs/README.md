## Notes

- ⚠ **Notes & Pages reconciliation flag (Spaces, 2026-07-15).** ADR-006 re-homes the tag primitive: N&P's
  `page_tags` ownership (its `structure-data.md`) is **superseded** by the universal `entity_tags`, and N&P becomes a
  **consumer** of Spaces' tags/views. N&P was documented in Wave 0 before Spaces existed as a concept, so its docs
  still describe page-only tags. This is a **build-phase reconciliation** (analogous to the Pomodoro Notes→Sessions
  boundary move): when Spaces or N&P is built, refresh N&P's structure-data/contract to consume `entity_tags` and
  retire `page_tags`. Recorded, not silently re-ordered — the fill-order rule ("never document against an
  undocumented foundation") is honored by flagging the retroactive dependency rather than pretending Spaces came first.
- ⚠ **Views need a build-time review pass (Victor, 2026-07-05).** The view/page structures documented per
  module (Wave 0→2) were captured at INTENT level and may carry gaps — the Books entity-modeling pass proved
  the pattern (B13–B16 surfaced only when correlations were drawn). Before building any module's UI, REVIEW
  its documented view structure, fill the gaps, and run the **/critique gate** on the refined views — the
  final deliverable must be the best UI/UX, not the intake sketch.
- The survey pruned 76 dirs — the 17 modules **aren't implemented in code yet** (they live in the ADR-002
  schema + `@vida/types`). Feature specs are harvested from **ADR-002 + `@vida/types` + legacy life-os**, not code.
