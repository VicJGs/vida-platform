## 1. Identity

- **What:** the note page's metadata controls stop being no-ops, and a page can be renamed.
  1. **Favorite · Archive · Icon · Cover persist** through `updatePage` and reflect state after the re-read (EC-7).
  2. **Icon** = a Lucide icon chosen from a grid (no emoji, EC-22/EC-29); the header and the collection rows/tiles show
     it, falling back to the type icon.
  3. **Cover** = paste an image link · use one of the page's attachments · remove (EC-29); the cover shows at the top of
     the Overview in both modes, and gallery tiles carry it.
  4. **Rename both ways** (EC-25): click the title to edit it in place (Enter/blur saves, Esc reverts), **and** ⋯ →
     "Rename" opens a small dialog. Both write the same title through the same mutation.
  5. **The R1 carry:** focus moves to the surface heading after a successful Retry; the ⋯ panel is labelled by its
     trigger; every mutation fails loud (`notifyError`).
- **Why:** slice-map R3 `[FACT: slice-map.md:63-76]`; metadata writes are no-ops today `[FACT: use-page-metadata.ts:27-38]`;
  the title is plain text `[FACT: entity-view.tsx:158-160]`.

## 3. Business rules (BR-R3-\*)

- **BR-R3-1 · Metadata persists.** Favorite, archive, icon and cover write through `updatePage`; the UI reflects the re-read
  (no optimistic patch). Archiving keeps the open page.
- **BR-R3-2 · Named key set.** Each mutation invalidates its G2 keys.
- **BR-R3-3 · Icon = a Lucide name** (kebab-case, shape-validated in core); the UI offers and renders a curated set and
  falls back to the type icon.
- **BR-R3-4 · Cover = an http(s) image URL or `attachment:<id>`,** shown at the top of the Overview in both modes; an
  attachment cover uses its thumbnail only (never the full blob); an unresolvable or failed cover shows a neutral
  placeholder. Remote images load with no referrer. Create and update validate icon/cover the same way.
- **BR-R3-5 · Rename both ways, one mutation.** Inline (Enter/blur saves, Esc reverts) and ⋯ → Rename dialog. An empty
  title stores null (the label fallback shows).
- **BR-R3-6 · Fails loud.** Each mutation's error → one toast naming it.
- **BR-R3-7 · Focus is never lost.** Esc returns focus to the title; closing a dialog returns focus to its trigger; a
  successful Retry focuses the surface heading.

## 4. Acceptance — Verification Gate + Visual Gate

**A. Vitest (core):** the shared icon/cover schemas through **both** `createPage` and `updatePage`: valid names (`star`, `book-open`) and covers
(`https://…`, `http://…`, `attachment:<uuid>`); rejected (`Star`, `⭐`, `javascript:…`, `data:…`, `ftp://…`, a 2049-char
URL, `attachment:`); `null` clears. `getAttachmentThumbnail(id)` → the thumbnail bytes, `null` when none or deleted.

**B. Vitest (ui — EntityView + CollectionView):** a `heading` level 1 with the title exists in every case, and the region is
named by it **before, during and after** an edit. Without `onTitleCommit` the heading holds plain text. With it, the title is a
button named by the title; Enter → an input named "Page title" with the text selected; Enter commits a changed trimmed
value once; blur commits; an unchanged value doesn't commit; Esc reverts with no commit and focus returns to the title;
`titleRef` points at the heading; the input seeds from `titleEditValue`. CollectionView `titleRef` points at its title.
Line-height test unchanged.

**C. Vitest (web):**

1. `usePageMetadata`: each toggle/set calls `updatePage` with the exact patch and invalidates its G2 keys; an error → one
   `notifyError` with its action.
2. Icon picker: a `radiogroup` of the curated set, the current icon `aria-checked`; arrow keys move focus + selection and
   write **nothing**; Enter/Space/click writes `icon` once and closes; "Remove icon" writes null; Esc closes with no write,
   and focus returns to "Change icon".
3. Cover picker: an invalid link shows an inline error and doesn't write; a valid link writes; the attachment section shows
   the honest empty line (stub); "Remove cover" writes null.
4. Rendering: a header with `icon:'book-open'` shows that icon; an unknown name → the type icon; a URL cover → `img` with
   `referrerpolicy="no-referrer"` and `alt=""`, at the top of the Overview in **merged and tabbed**; an image `error` event →
   the placeholder; an attachment cover reads the thumbnail (mocked), never the full blob; rows/tiles carry icon + cover; the
   controls show icon + label in the greybox order (G16), each control's accessible name equal to its visible label.
5. Rename: inline Enter → one `updatePage(id,{title})` + the rename keys; the ⋯ menu shows "Rename" → the dialog → Save →
   the same mutation; empty → `title:null`; the ⋯ panel's `aria-labelledby` → the trigger.
6. Focus after Retry (page, collection, Home): error → Retry → success moves focus to the target; a first load doesn't.
