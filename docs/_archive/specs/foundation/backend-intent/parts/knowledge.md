# Backend Intent — Part A: knowledge

> Scope: the **knowledge** module + its HOSTED sub-context **flashcards** (a study-method service that lives
> inside Knowledge — `docs/features/knowledge/flashcards/*`). Knowledge OWNS the generic **review engine**
> (methods registry / bindings / curves / review-event log / due-provider / mastery derivation + rollup); this
> engine is heavily cross-cutting (consumed by flashcards + future assessments/self-test/Feynman + Education +
> Skills/Languages/Finance/Health via compound sets). All rows are ⚠ INTENDED unless a FACT-base column is
> cited — the FACT base is 3 schema-only tables with 0 lines of service logic (`models/learning.ts` empty).
>
> No `docs/intake/knowledge.md` §E and no `part-1.2-reruns/knowledge.md` exist; Knowledge is an M1.2 module so
> it has **no §9 bucket** in `m1.1-delivery-plan.md` (only M1.1 modules do — confirmed). Sources used: S1
> (5-aspect knowledge + flashcards docs), S2 (intake), S8 (CLAUDE.md §7).
